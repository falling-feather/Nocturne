## 1. 项目简介

夜航（Nocturne）是面向 Windows 的本地优先轻量笔记软件，品牌标语为“所见所思，杂而成章。”桌面端围绕主笔记、富文本与图片、可多开的桌面置顶便签和日常待办构成核心工作流，目标是在游戏或其他高负载应用运行时仍能低打扰驻留，并可通过全局快捷键快速记录灵感。多枚散落便签可以“收舟入册”为带来源记录的正式笔记；数据库与附件可在后台生成一致性本地备份，均不依赖在线账号。

## 2. 宏观背景

项目希望在传统纸面记录与完整办公文档之间提供更轻的选择：保留图片、富文本和集中管理能力，同时避免浏览器内核、在线账号和大型办公套件成为基本运行依赖。当前原型已经验证 C++、Qt Widgets 与 SQLite 的基本可行性，后续优化以可测量的启动、常驻、加载和数据可靠性结果为判断依据。

## 3. 大体技术栈

| 领域 | 技术 | 在项目中的主要作用 |
| --- | --- | --- |
| 语言 | C++17 | 桌面应用逻辑、数据访问与 Windows 平台接入 |
| 桌面界面 | Qt 6 Widgets | 主窗口、富文本编辑器、快速便签、待办和托盘 |
| 本地数据 | SQLite、Qt SQL | 笔记、分组、待办和设置的持久化 |
| Windows 接入 | Win32 `user32` | 全局快捷键、无边框窗口原生拖动命中与八向缩放 |
| 品牌资源 | SVG、PNG、ICO、Qt Resource System | 金月、墨舟、旅人与朱旗图标，窗口/托盘图标与 Windows 可执行文件元数据 |
| 构建与部署 | CMake、Ninja、PowerShell | Release 构建、测试和便携包收集 |

## 4. 产品边界

- 当前开发范围只包含 Windows 电脑端。
- 手机端、云同步、账号和多人实时协作暂不进入本轮实现。
- HTML、Markdown 与 TXT 是当前交换格式；复杂格式往返不承诺完全无损。
- 原型提供每日一次的本地自动备份与手动备份，但没有加密、云端副本和一键恢复；重要资料仍应保留独立可信副本。
