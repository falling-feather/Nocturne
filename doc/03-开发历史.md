# FeatherNote — 开发历史

> **文档梗概**：记录已经发生且能够由仓库核验的独立 Git 提交，以及大版本和中版本形成的实际结果。
>
> **具体规划法则**：
>
> 1. 开发历史中的提交标题必须与实际 Git 提交标题一致。
> 2. 一次提交只对应一个版本号和一个任务编号。
> 3. 既有历史不因后续修改、清理或回滚删除。
>
> **最后一次更新时间**：2026-08-31
>
> **更新者**：发布组
