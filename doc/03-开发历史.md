## 3. 独立提交记录

### 3.1 V0.1.0

- **提交日期**：2026-08-31
- **Git 提交**：`V0.1.0 chore(repo): 建立原型与文档基线（REL-001）`
- **具体完成**：初始化 Git 仓库；排除构建产物、便携包和本机数据库；纳入当前 Qt/SQLite 原型源码、构建测试脚本；建立 `doc/00—03` 权威文档入口并保留旧文档兼容链接。
- **关联说明**：[项目总纲的既有文档兼容](00-项目总纲.md#6-既有文档兼容)、[REL-001 任务原件](02-项目规划.md#4-任务安排)

### 3.2 V0.1.1

- **提交日期**：2026-08-31
- **Git 提交**：`V0.1.1 feat(desktop): 优化按需加载与笔记管理（DEV-001）`
- **具体完成**：将数据库升级到 schema v2 并支持旧库幂等迁移；用不含正文的摘要查询、正文版本/SHA-256 校验和 24 MiB 加权 LRU 缓存减少列表与切换开销；加入分组 CRUD、筛选、移动和显式重命名；把旧快捷便签迁移为正式笔记并保持主列表联动；限制本地大图解码尺寸；加入隔离 UI 测试配置；显式设置浅色菜单各状态的深色文字，修复 Windows 深色主题下白底白字；让打包目录自动采用 CMake 项目版本。
- **关联说明**：[DEV-001 任务原件](02-项目规划.md#4-任务安排)、[开发者文档](01-开发者文档.md)

### 3.3 V0.1.2

- **提交日期**：2026-08-31
- **Git 提交**：`V0.1.2 ui(desktop): 实装夜航品牌与古典夜色界面（DEV-002）`
- **具体完成**：把用户确认的“夜航 / Nocturne”与“所见所思，杂而成章。”写入主窗口、便签、托盘和可见元数据；建立月帆夜舟 SVG 权威源、多尺寸 PNG、ICO、Qt 资源和 Windows 版本资源；把主窗口重构为深靛导航、宣纸编辑与月白待办三栏界面，把格式栏拆成防挤压的两层布局；将弹出菜单和组合框改为应用级显式调色，修复深色系统主题下白底白字；保留旧 `FeatherNote` 内部存储身份以原位读取既有数据；在纯英文构建目录编译 RC/ICO，完成 Release、CTest、便携包与隔离 UI 冒烟。
- **关联说明**：[DEV-002 任务原件](02-项目规划.md#4-任务安排)、[开发者文档](01-开发者文档.md)

### 3.4 V0.1.3

- **提交日期**：2026-09-01
- **Git 提交**：`V0.1.3 feat(desktop): 完善多便签与轻量夜航界面（DEV-003）`
- **具体完成**：把用户选定的金月、墨舟、斗笠旅人和朱旗造型重绘为透明 SVG 权威源并生成多尺寸 PNG/ICO；用 `WindowChrome` 统一主窗口与便签的无边框拖动、最大化与八向缩放；将便签从预创建单例改为按需创建的多窗口，每枚以笔记 ID 独立保存内容、置顶、透明度、位置、尺寸和打开状态，并通过 schema v3 原位移除旧单便签索引；把主界面改为连续平面、细分隔、左侧选中线和线性控件，移除阴影、装饰渐变及重复品牌卡片，用无动画程序化星点/月舟/水纹替代装饰背景位图及缩放缓存；主窗口隐藏/最小化时清理正文缓存和当前排版文档；加入持久化/迁移、600 篇性能、真实 QWidget UI 三项自动回归和开发机启动/后台资源采样；建立官方来源竞品矩阵与“灵感航迹、便签入册、静默航行、灵感包”差异化路线；完成 Release、CTest、截图、EXE 资源与便携包核验。
- **关联说明**：[DEV-003 任务原件](02-项目规划.md#4-任务安排)、[开发者文档](01-开发者文档.md)、[竞品调研](04-竞品调研与差异化方向.md)
