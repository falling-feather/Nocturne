## 0. 当前基线与硬规则

**当前基线**：Git 提交基线为 `V0.1.1`。它具备摘要列表、按需正文、版本校验缓存、分组、正式入库便签、富文本与图片、待办、托盘和便携打包脚本。

**当前任务入口**：[DEV-001 电脑端本地数据与笔记管理升级](02-项目规划.md#4-任务安排)

**硬规则**：

1. 构建目录、便携包和用户数据库不得进入 Git。
2. 程序运行期间不得把 `notebook.sqlite3-wal` 或 `notebook.sqlite3-shm` 当作可独立删除的缓存。
3. 数据库连接由创建它的线程使用；不得把当前 `QSqlDatabase` 连接直接交给后台线程。
4. 关闭主窗口默认只隐藏到托盘；需要备份、替换数据库或更新程序时必须从托盘完全退出。

## 1. 项目与系统定位

FeatherNote 是单进程、单用户、本地优先的 Windows 桌面笔记原型。主窗口负责整理富文本笔记与待办，工具窗口负责快速便签，系统托盘负责后台驻留。当前没有账号、网络服务、手机端、云同步或多人权限边界。

## 2. 总体架构

```text
src/main.cpp
  ├─ 单实例锁、应用元数据与隔离测试配置
  ├─ Database
  │    └─ QSQLITE → notebook.sqlite3（notes、folders、todos、settings、可选 FTS5）
  └─ MainWindow
       ├─ 摘要列表 → 选中后读取正文 → 24 MiB 加权缓存
       ├─ NoteEditor → 富文本、图片输入与有界图片解码
       ├─ StickyNoteWindow → notes.kind = sticky
       ├─ 分组筛选、移动与管理
       ├─ 待办列表
       ├─ QSystemTrayIcon
       └─ Win32 RegisterHotKey
```

`main.cpp` 创建并打开唯一 `Database`，再把其地址交给 `MainWindow`。主列表只查询 `NoteSummary`，不选择 HTML 或纯文本正文；`loadNote()` 仅在选中项的缓存缺失或 `body_revision` 不匹配时读取完整 `NoteRecord`。`MainWindow` 和 `StickyNoteWindow` 在 GUI 线程同步调用数据库；图片作为 PNG 文件写入应用数据目录，HTML 保存本地文件 URL。

缓存刻意保存正文数据而不是多个完整 `QTextDocument`：后者会长期保留排版树和图片资源，与低常驻内存目标冲突。界面始终只保留一篇正在编辑的渲染文档，最近正文按估算 UTF-16 字节数进入 24 MiB LRU 缓存；摘要中的 `body_revision` 负责判断缓存是否仍有效，SHA-256 `content_hash` 负责避免把元数据变化误判成正文变化。

## 5. 入口与运行流程

1. `main.cpp` 设置组织名和应用名，并以 `QLockFile` 阻止第二实例。
2. `Database::open()` 创建应用数据目录、打开 `notebook.sqlite3`，设置 `busy_timeout`、WAL、`synchronous=NORMAL` 和外键；只有 `user_version` 低于 2 时才在事务中迁移表、摘要、SHA-256 哈希、正文版本和旧 `settings.quick_note`，高于当前版本时拒绝降级打开。
3. 数据库尝试建立 FTS5 trigram 索引；不可用时自动退回 `LIKE` 搜索。三字及以上查询走 `MATCH`，一至二字查询走兼容回退。
4. `MainWindow` 构建界面、托盘和全局快捷键，创建欢迎笔记，只读取笔记摘要与待办；选中笔记时按需读取正文。
5. 标题或正文变化启动约 `650 ms` 的单次定时器；正文哈希不变时不增加 `body_revision`，没有脏状态时不会因切换或退出重复写入。
6. 主窗口关闭时先保存再隐藏到托盘；托盘“退出”保存便签、几何状态并结束进程。

## 7. 接口、数据与状态

| 方法或事件 | 调用方 | 输入 | 输出 | 失败行为 | 实现位置 |
| --- | --- | --- | --- | --- | --- |
| `Database::listNoteSummaries()` | 主窗口 | 搜索文本、分组筛选 | 不含正文的 `NoteSummary` 列表 | 返回空列表并填写错误 | `src/Database.cpp` |
| `Database::note()` | 主窗口 | 笔记 ID | 可选完整笔记 | 未找到返回空可选值 | `src/Database.cpp` |
| `createNote/updateNote/renameNote/softDeleteNote` | 主窗口 | 标题、HTML、纯文本或 ID | ID 或成功状态 | 事务回滚并填写错误 | `src/Database.cpp` |
| `listFolders/createFolder/renameFolder/deleteFolder/moveNoteToFolder` | 主窗口 | 分组名、分组 ID 或笔记 ID | 记录、ID 或成功状态 | 删除分组时笔记回到未分组 | `src/Database.cpp` |
| `stickyNote/saveStickyNote` | 便签窗口 | 纯文本 | 正式便签记录或 ID | 保留脏状态并显示失败 | `src/Database.cpp` |
| `imagePasted/imageFilesDropped` | `NoteEditor` | 图片或路径 | Qt 信号 | 不支持的 MIME 交回 `QTextEdit` | `src/NoteEditor.cpp` |

当前数据库位于 `QStandardPaths::AppLocalDataLocation`：

| 表 | 权威内容 | 删除规则 |
| --- | --- | --- |
| `notes` | 分组、类型、标题、HTML、纯文本、摘要、正文版本、SHA-256 哈希和时间 | `deleted_at` 软删除；活动便签最多一条 |
| `folders` | 分组名称、可选父级和排序 | 删除时笔记移回未分组，子组父级置空 |
| `todos` | 待办文本、完成状态和排序 | 清理已完成时物理删除 |
| `settings` | 兼容保留的小型键值 | 旧 `quick_note` 在 schema v2 升级事务中迁移后删除 |
| `notes_fts` | 可选 FTS5 外部内容索引 | 由 `notes` 触发器维护；不可用不阻止数据库启动 |

图片文件位于同一数据根目录的 `attachments/`。数据库和附件目录共同构成完整用户数据。

## 8. 页面、布局与操作规范

| 页面或窗口 | 入口 | 布局区域 | 主要组件 | 状态与权限 | 实现文件 |
| --- | --- | --- | --- | --- | --- |
| 主窗口 | 程序启动、托盘打开 | 左侧摘要与分组筛选、中间编辑器与笔记分组、右侧待办 | 搜索、摘要列表、显式重命名、分组、编辑器、待办 | 便签正文在主编辑器只读，避免双窗口互相覆盖 | `src/MainWindow.cpp` |
| 快速便签 | `Ctrl+Alt+N`、主窗口或托盘 | 标题提示与纯文本编辑区 | `QTextEdit`、保存提示 | 置顶工具窗口 | `src/StickyNoteWindow.cpp` |

标题框直接承担笔记重命名，`F2` 和列表右键提供显式入口。左侧组合框筛选分组，编辑器工具栏组合框移动当前笔记；`Ctrl+Shift+G` 新建分组。列表切换前保存当前脏笔记；搜索输入约 `180 ms` 防抖。关闭主窗口不等于退出，托盘退出才释放数据库和快捷键。

主题样式必须同时声明浅色菜单的背景色与所有文字状态，不能依赖 Windows 系统调色板；`MainWindow::applyTheme()` 显式定义普通、选中和禁用菜单项的前景色，以及分隔线颜色，以保证系统深色主题下仍有足够对比度。

## 10. 开发与运行操作

### 10.1 环境准备

在项目根目录使用 Windows PowerShell。已知环境是 `D:/msys64/ucrt64` 的 CMake、Ninja、MinGW 和 Qt 6.10.1；不得在同一构建目录混用 ABI。

### 10.2 启动与停止

```powershell
.\build.ps1 -Configuration Release
& "$env:LOCALAPPDATA\FeatherNotePrototypeBuild\Release\FeatherNote.exe"
```

正常结果是主窗口出现且可创建笔记。停止时从托盘选择“退出”；若只是关闭主窗口，进程仍然运行。

### 10.3 构建、测试与调试

```powershell
.\build.ps1 -Configuration Release
.\build.ps1 -Configuration Release -Package
```

第一条命令默认构建并运行 CTest；第二条还生成 `dist/FeatherNote-0.1.1-portable/`。包版本由 `scripts/package.ps1` 从 `CMakeLists.txt` 读取，不能另设一份硬编码版本。失败时先检查 PowerShell 输出中的 CMake、编译器、Qt 插件或 `ldd` 缺失项。

## 11. 修改与扩展指南

修改持久化能力时，先在 `02-项目规划.md` 建立任务，再同时调整 `Database.h/.cpp` 和 `tests/DatabaseSmoke.cpp`。schema 变化必须对已存在数据库幂等执行，禁止只修改新建表语句。修改主界面交互时同步 `MainWindow.h/.cpp`；修改图片 MIME 接入时同步 `NoteEditor.h/.cpp`。稳定实现形成后更新本文，并在同一提交中更新任务状态和开发历史。

## 12. 测试与验证

自动入口是 CMake 目标 `FeatherNotePersistenceTest`；`build.ps1` 默认通过 CTest 执行。它从真实 `0.1.0` 旧 schema 起步，验证 schema v2 迁移、摘要搜索、正文哈希与版本、元数据重命名、分组 CRUD/筛选/安全删除、便签迁移与兼容接口、待办、软删除和幂等重启。

> 下列清单是操作模板，不代表当前项目进度。

- [ ] Release 构建成功且 CTest 全部通过。
- [ ] 新建、重命名、分组、切换、搜索、缓存命中和重启恢复笔记。
- [ ] `Ctrl+Alt+N` 或 `Ctrl+Shift+N` 呼出同一便签，并确认保存后出现在主列表。
- [ ] 图片粘贴、拖入与选择后可显示，重启后仍可读取。
- [ ] 主窗口关闭后仍可从托盘打开，托盘退出后进程结束。

## 13. 维护与故障排查

| 维护或故障 | 表现 | 准确位置 | 操作或诊断 | 正常结果 | 相关规则 |
| --- | --- | --- | --- | --- | --- |
| 快捷键冲突 | 状态栏提示被占用 | `GlobalHotkey` | 关闭占用程序或用界面按钮 | 主程序继续可用 | 快捷键失败不得阻止启动 |
| 深色系统主题下菜单文字不可读 | 浅色菜单继承白色系统文字 | `MainWindow::applyTheme()` | 检查 `QMenu` 普通、选中、禁用状态是否均显式声明前景色 | 菜单文字保持深色且分隔线可见 | 自定义浅色背景不得依赖系统前景色 |
| 数据备份 | 运行时存在 WAL/SHM | 应用数据根 | 托盘完全退出后复制整个目录 | 数据库与附件同时存在 | 禁止只复制在线主库 |
| 中文路径构建失败 | `moc` 无法写中间文件 | `build.ps1` | 使用脚本的纯英文临时目录 | Release 构建通过 | 不把临时目录改回源码旁 |
| 便携包缺 DLL | 启动时报模块缺失 | `scripts/package.ps1` | 检查 `windeployqt` 和递归 `ldd` 输出 | 依赖扫描无未解析项 | 不手工复制整套工具链 |
