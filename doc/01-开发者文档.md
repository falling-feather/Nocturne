## 0. 当前基线与硬规则

**当前基线**：`V0.1.0` Qt 桌面原型；具备主笔记、富文本与图片、单一快速便签、待办、托盘、全局快捷键、SQLite 持久化和便携打包脚本。

**当前任务入口**：[DEV-001 电脑端本地数据与笔记管理升级](02-项目规划.md#4-任务安排)

**硬规则**：

1. 构建目录、便携包和用户数据库不得进入 Git。
2. 程序运行期间不得把 `notebook.sqlite3-wal` 或 `notebook.sqlite3-shm` 当作可独立删除的缓存。
3. 数据库连接由创建它的线程使用；不得把当前 `QSqlDatabase` 连接直接交给后台线程。
4. 关闭主窗口默认只隐藏到托盘；需要备份、替换数据库或更新程序时必须从托盘完全退出。

## 1. 项目与系统定位

FeatherNote 是单进程、单用户、本地优先的 Windows 桌面笔记原型。主窗口负责整理富文本笔记与待办，工具窗口负责快速便签，系统托盘负责后台驻留。当前没有账号、网络服务、手机端、云同步或多人权限边界。

## 2. 总体架构

```text
src/main.cpp
  ├─ 单实例锁与应用元数据
  ├─ Database
  │    └─ QSQLITE → notebook.sqlite3（notes、todos、settings）
  └─ MainWindow
       ├─ NoteEditor → 富文本与图片输入
       ├─ StickyNoteWindow → settings.quick_note
       ├─ 待办列表
       ├─ QSystemTrayIcon
       └─ Win32 RegisterHotKey
```

`main.cpp` 创建并打开唯一 `Database`，再把其地址交给 `MainWindow`。`MainWindow` 和 `StickyNoteWindow` 在 GUI 线程同步调用数据库；图片作为 PNG 文件写入应用数据目录，HTML 保存本地文件 URL。

## 3. 技术栈与依赖

| 层级或领域 | 技术 | 版本 | 用途 | 配置位置 |
| --- | --- | --- | --- | --- |
| 语言 | C++ | C++17 | 应用逻辑与平台接入 | `CMakeLists.txt` |
| UI | Qt Widgets | 最低 6.5；已知环境 6.10.1 | 窗口、编辑器、托盘和控件 | `CMakeLists.txt`、`src/` |

| 打包 | PowerShell、`windeployqt`、`ldd` | 以本机安装为准 | 收集 Qt 插件和运行库 | `scripts/package.ps1` |

## 4. 文件与目录结构

```text
FeatherNote/
├── src/                    # 桌面运行代码
│   ├── main.cpp            # 单实例、数据库和主窗口入口
│   ├── Database.*          # SQLite schema 与 CRUD
│   ├── MainWindow.*        # 主界面、托盘、快捷键和业务接线
│   ├── NoteEditor.*        # 富文本图片粘贴和拖放适配
│   └── StickyNoteWindow.*  # 置顶便签及自动保存
├── tests/                  # 数据库烟雾测试
├── scripts/                # 打包脚本
├── packaging/              # Qt 运行时配置
├── doc/                    # 当前权威项目文档
├── docs/                   # 既有 0.1.0 原型兼容说明
├── CMakeLists.txt          # 构建目标和测试目标
├── build.ps1               # 构建、测试和打包入口
└── README.md               # 测试者入口与备份说明
```

`build/`、`build-*` 与 `dist/` 是生成物，不属于源码。

## 5. 入口与运行流程

1. `main.cpp` 设置组织名和应用名，并以 `QLockFile` 阻止第二实例。
2. `Database::open()` 创建应用数据目录、打开 `notebook.sqlite3`，设置 `busy_timeout`、WAL、`synchronous=NORMAL` 和外键，再幂等创建表与索引。
3. `MainWindow` 构建界面、托盘和全局快捷键，创建欢迎笔记，读取笔记与待办。
4. 标题或正文变化启动约 `650 ms` 的单次定时器；超时后写回数据库。
5. 主窗口关闭时先保存再隐藏到托盘；托盘“退出”保存便签、几何状态并结束进程。

## 6. 模块与功能实现

| 模块 | 路径 | 职责与边界 | 入口 | 依赖与调用方 | 验证 |
| --- | --- | --- | --- | --- | --- |
| 数据库 | `src/Database.*` | schema、笔记、待办和设置持久化；不负责 UI | `Database::open()` | Qt SQL；由主窗口与便签调用 | `FeatherNotePersistenceTest` |
| 主窗口 | `src/MainWindow.*` | 组合导航、编辑器、待办、托盘和快捷键 | `MainWindow` 构造函数 | `Database`、`NoteEditor`、`StickyNoteWindow` | 人工 UI 冒烟 |
| 编辑器 | `src/NoteEditor.*` | 识别剪贴板和拖放图片；其余文本行为交给 `QTextEdit` | `insertFromMimeData()` | 由主窗口创建并接收图片信号 | 粘贴、拖放和保存后重启 |
| 快速便签 | `src/StickyNoteWindow.*` | 单一置顶纯文本窗口、几何保存和防抖持久化 | `summon()`、`flushSave()` | 调用 `Database::saveQuickNote()` | 快捷键输入与重启恢复 |
| 构建打包 | `build.ps1`、`scripts/package.ps1` | 纯英文中间目录、CTest 和便携依赖收集 | PowerShell 参数 | CMake、Ninja、Qt 工具链 | Release 构建与包启动 |

## 7. 接口、数据与状态

| 方法或事件 | 调用方 | 输入 | 输出 | 失败行为 | 实现位置 |
| --- | --- | --- | --- | --- | --- |
| `Database::listNotes()` | 主窗口 | 搜索文本 | 完整 `NoteRecord` 列表 | 返回空列表并填写错误 | `src/Database.cpp` |
| `Database::note()` | 主窗口 | 笔记 ID | 可选完整笔记 | 未找到返回空可选值 | `src/Database.cpp` |
| `createNote/updateNote/softDeleteNote` | 主窗口 | 标题、HTML、纯文本或 ID | ID 或成功状态 | 事务回滚并填写错误 | `src/Database.cpp` |
| `quickNote/saveQuickNote` | 便签窗口 | 纯文本 | 文本或成功状态 | 保留脏状态并显示失败 | `src/Database.cpp` |
| `imagePasted/imageFilesDropped` | `NoteEditor` | 图片或路径 | Qt 信号 | 不支持的 MIME 交回 `QTextEdit` | `src/NoteEditor.cpp` |

当前数据库位于 `QStandardPaths::AppLocalDataLocation`：

| 表 | 权威内容 | 删除规则 |
| --- | --- | --- |
| `notes` | 标题、HTML、纯文本和时间 | `deleted_at` 软删除 |
| `todos` | 待办文本、完成状态和排序 | 清理已完成时物理删除 |
| `settings` | `quick_note` 等小型键值 | 按键覆盖 |

图片文件位于同一数据根目录的 `attachments/`。数据库和附件目录共同构成完整用户数据。

## 8. 页面、布局与操作规范

| 页面或窗口 | 入口 | 布局区域 | 主要组件 | 状态与权限 | 实现文件 |
| --- | --- | --- | --- | --- | --- |
| 主窗口 | 程序启动、托盘打开 | 左侧笔记、中间编辑器、右侧待办 | 搜索、列表、标题、工具栏、编辑器、待办 | 本地单用户，无权限层 | `src/MainWindow.cpp` |
| 快速便签 | `Ctrl+Alt+N`、主窗口或托盘 | 标题提示与纯文本编辑区 | `QTextEdit`、保存提示 | 置顶工具窗口 | `src/StickyNoteWindow.cpp` |

标题框直接承担笔记重命名。列表切换前保存当前脏笔记；搜索输入约 `180 ms` 防抖。关闭主窗口不等于退出，托盘退出才释放数据库和快捷键。

## 10. 开发与运行操作

### 10.1 环境准备

在项目根目录使用 Windows PowerShell。已知环境是 `D:/msys64/ucrt64` 的 CMake、Ninja、MinGW 和 Qt 6.10.1；不得在同一构建目录混用 ABI。

### 10.2 启动与停止

```powershell
.\build.ps1 -Configuration Release
& "$env:LOCALAPPDATA\FeatherNotePrototypeBuild\Release\FeatherNote.exe"
```

正常结果是主窗口出现且可创建笔记。停止时从托盘选择“退出”；若只是关闭主窗口，进程仍然运行。

### 10.3 构建、测试与调试

```powershell
.\build.ps1 -Configuration Release
.\build.ps1 -Configuration Release -Package
```

第一条命令默认构建并运行 CTest；第二条还生成 `dist/FeatherNote-0.1.0-portable/`。失败时先检查 PowerShell 输出中的 CMake、编译器、Qt 插件或 `ldd` 缺失项。

## 11. 修改与扩展指南

修改持久化能力时，先在 `02-项目规划.md` 建立任务，再同时调整 `Database.h/.cpp` 和 `tests/DatabaseSmoke.cpp`。schema 变化必须对已存在数据库幂等执行，禁止只修改新建表语句。修改主界面交互时同步 `MainWindow.h/.cpp`；修改图片 MIME 接入时同步 `NoteEditor.h/.cpp`。稳定实现形成后更新本文，并在同一提交中更新任务状态和开发历史。

## 12. 测试与验证

自动入口是 CMake 目标 `FeatherNotePersistenceTest`；`build.ps1` 默认通过 CTest 执行。它验证笔记、搜索、待办、快速便签、软删除和数据库重启后的持久化。

> 下列清单是操作模板，不代表当前项目进度。

- [ ] Release 构建成功且 CTest 全部通过。
- [ ] 新建、编辑、切换、搜索和重启恢复笔记。
- [ ] `Ctrl+Alt+N` 呼出同一便签并在重启后恢复内容。
- [ ] 图片粘贴、拖入与选择后可显示，重启后仍可读取。
- [ ] 主窗口关闭后仍可从托盘打开，托盘退出后进程结束。

## 13. 维护与故障排查

| 维护或故障 | 表现 | 准确位置 | 操作或诊断 | 正常结果 | 相关规则 |
| --- | --- | --- | --- | --- | --- |
| 快捷键冲突 | 状态栏提示被占用 | `GlobalHotkey` | 关闭占用程序或用界面按钮 | 主程序继续可用 | 快捷键失败不得阻止启动 |
| 数据备份 | 运行时存在 WAL/SHM | 应用数据根 | 托盘完全退出后复制整个目录 | 数据库与附件同时存在 | 禁止只复制在线主库 |
| 中文路径构建失败 | `moc` 无法写中间文件 | `build.ps1` | 使用脚本的纯英文临时目录 | Release 构建通过 | 不把临时目录改回源码旁 |
| 便携包缺 DLL | 启动时报模块缺失 | `scripts/package.ps1` | 检查 `windeployqt` 和递归 `ldd` 输出 | 依赖扫描无未解析项 | 不手工复制整套工具链 |
